Primary action button for TRACK screens; use `primary` (academic blue) for the main action per view, `accent` (growth green) for positive creation actions.

```jsx
<Button icon="plus">إنشاء مبادرة</Button>
```

Variants: primary, accent, secondary, ghost, danger. Sizes sm/md/lg (32/40/48px). `icon`/`iconEnd` take Lucide names; in RTL `icon` sits on the right.
