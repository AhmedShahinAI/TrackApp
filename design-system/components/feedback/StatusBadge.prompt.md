Status pill with a fixed bilingual label — accounts, terms, enrollments, imports, import rows, shared access.

```jsx
<StatusBadge status="withdrawn"/>
<StatusBadge status="shared"/>
<StatusBadge status="draft" lang="en"/>
```

Statuses: active, completed, progress, late, pending, notStarted, closed, draft, archived, withdrawn, inactive, failed, queued, running, warning, error, valid, shared, current. Label follows `<html lang>` unless `lang` is passed.
