Numbered horizontal step indicator — the six-step roster Import Wizard (upload → mapping → checking → preview → import → report).

```jsx
<Stepper steps={['رفع الملف','مطابقة الأعمدة','الفحص','المعاينة','الاستيراد','التقرير']} current={2}/>
```

Done steps turn green with a check; the active step is academic blue with a soft ring.
